ROCKFIELD SCHOOLS WEBSITE

Pages: index.html (home), results.html (staff portal, sign-in), check-result.html (students).

Publishing results to students
1. Staff portal > Publish > print PIN slips per class, give each student theirs.
2. Publish all results: downloads published.json.
3. Replace data/published.json on the website with that file.

Security notes
- Staff sign-in protects the portal screen on the computer being used. Scores are stored in that browser, so use the same computer and download backups (Settings).
- Student results are encrypted. Only the right code and PIN can open them.
- The site must be on https (e.g. GitHub Pages) or localhost for sign-in and result checking to work.
